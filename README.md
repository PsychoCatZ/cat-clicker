# Котокликер

Локальная браузерная игра на Vite, React, TypeScript и CSS. Нажимайте на кота, собирайте рыбок, обставляйте комнаты и спасите всех 25 котов.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Производственная сборка: `npm run build`, просмотр сборки: `npm run preview`.

## Правила

- Пять комнат. В каждой есть пять котов и десять оригинальных улучшений. Первый кот доступен сразу. Чтобы открылась дверь в следующую комнату, соберите всех пятерых котов и купите все десять улучшений.
- У каждой комнаты отдельные рыбки, уровень ресурсов, доход за клик, пассивный доход и сытость. В предыдущие комнаты можно возвращаться, их прогресс сохраняется.
- Пять ресурсов в магазине увеличивают доход за клик. Их можно покупать повторно: каждый новый уровень даёт такой же бонус, а цена растёт. Улучшения покупаются один раз и увеличивают рыбок в секунду.
- После покупки улучшение сразу приносит пассивный доход, а его изображение попадает в панель под комнатой. Нажмите «Расставить» и перетащите предмет в комнату или выберите его и коснитесь места. Размещение необязательно; предмет можно передвинуть позже. Настенные предметы размещаются на стене, напольные — на полу.
- После пяти обычных улучшений можно покупать пять продвинутых. Продвинутый предмет заменяет обычный в комнате; доход обоих предметов сохраняется.
- Шкала голода уменьшается, пока открыта игра. Когда она пустеет, наступает ночное состояние, кот спит и клики перестают приносить рыбок. Пассивный доход продолжает поступать. Мышка восстанавливает 25%, сухой корм 50%, влажный корм 100%, икра 100% и удваивает доход за клик на минуту.
- Свет можно выключить вручную: кот уснёт, клики остановятся, а сытость перестанет расходоваться. Пассивный доход продолжит поступать. Включите свет, чтобы снова собирать рыбок; выбор сохраняется отдельно в каждой комнате.
- Если кот спит, рыбок на мышку нет и ни одно улучшение ещё не куплено, включается минимальный пассивный доход. От нуля до цены мышки требуется около 30 минут.
- После завершения пятой комнаты появляется финал с предложением пройти игру в режиме «Эксперт». Он сбрасывает прохождение, повышает цены и ускоряет голод.
- В разделе «Мини-игра» доступен спокойный раунд «Котики в ряд»: поле 7×7, 20 ходов и без таймера. Выберите котика и соседнего с ним. Ошибочная перестановка не расходует ход, а совпадения из четырёх и пяти котиков дают больше очков.
- Мини-игра использует пять котов текущей комнаты. Каскады увеличивают комбо, а поле без возможных ходов перемешивается автоматически. При завершении или досрочном выходе очки котифицируются в рыбки той комнаты, где был начат раунд. Мини-игра не нужна для открытия комнат.
- Там же доступна спокойная игра «Найди пару» без таймера с тремя размерами поля: 10, 16 или 20 карточек. Используются пять котов текущей комнаты; на больших полях один кот может образовывать несколько пар. После двух несовпавших карточек поле ненадолго блокируется, а найденные пары остаются открытыми. За завершение с меньшим числом попыток начисляется бонус.
- После запуска обе мини-игры переходят в сосредоточенный полноэкранный режим без комнаты, магазинов и навигации. Активный раунд сохраняется; при досрочном выходе уже заработанная награда отправляется в стартовую комнату.

Прогресс, расстановка предметов и незаконченный раунд мини-игры автоматически хранятся в `localStorage` этого браузера. На телефоне предметы сначала используют положение с широкого экрана; их можно переставить отдельно, не меняя широкую версию. Сброс всего прогресса требует подтверждения. Старые сохранения переносятся автоматически.

Во время отсутствия все уже открытые комнаты продолжают получать пассивный доход, а сытость расходуется в комнатах с включённым светом. Выключенный свет сохраняет сытость, но не останавливает пассивный доход. За один период отсутствия учитывается не больше восьми часов; таймер икры при этом идёт по реальному времени. После возвращения показывается общая сводка дохода и расхода сытости.

## Ассеты

Исходные PNG-листы лежат в корне проекта. Нарезанные изображения находятся в `public/assets/`. Для повторной нарезки нужны Python, Pillow и NumPy:

```bash
pip install -r tools/requirements.txt
python tools/slice_assets.py
```

Нарезчик анализирует прозрачность, объединяет отделённые детали с основным предметом и сохраняет PNG с прозрачным отступом. Листы с соприкасающимися супергеройскими котами разделяются по их расположению на листе. Фоны комнат, пять фонов match-3 и финальная иллюстрация копируются без изменения.

## Структура

- `src/game/` — данные котов, комнат, предметов, игровая экономика и чистая логика обеих мини-игр.
- `src/components/` — интерфейс игры.
- `public/assets/` — изображения для браузера.
- `tools/` — нарезчик исходных изображений и проверка игровых правил.

Полная проверка игровой логики: `npm run check`. Отдельные проверки: `npm run check:game`, `npm run check:match3` и `npm run check:pairs`.
