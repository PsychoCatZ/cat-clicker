# Котокликер

Простой браузерный котокликер на Vite, React, TypeScript и CSS. Нажимайте на кота, собирайте рыбок, покупайте улучшения и открывайте новых котов.

## Игра

- За нажатие на кота начисляются рыбки. Начальный доход — 1 рыбка за клик.
- Миска с рыбой и игрушечная мышь увеличивают доход за клик. Лежанка, когтеточка и клубок дают рыбок каждую секунду. Цена следующего уровня растёт.
- Первый кот доступен сразу. Ещё четырёх базовых котов можно открыть за рыбки; купленные коты остаются в коллекции и доступны для переключения.
- Рыбки, улучшения и коллекция сохраняются в `localStorage` браузера. Кнопка сброса удаляет игровой прогресс после подтверждения.

Редкие и особые коты включены в данные проекта для будущего расширения, но в текущей версии их нельзя открыть. Сервер и аккаунт не нужны.

## Запуск

В корне проекта выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite в терминале. Для проверки производственной сборки выполните `npm run build`; для её локального просмотра — `npm run preview`.

## Ассеты

Исходные PNG-листы находятся в корне проекта. Нарезанные изображения и фоны, которые не требуют нарезки, находятся в `public/assets/`. Для повторной нарезки установите Python, Pillow и NumPy:

```bash
pip install -r tools/requirements.txt
python tools/slice_assets.py
```

Утилита `tools/slice_assets.py` находит отдельные объекты по alpha-каналу, добавляет прозрачный отступ и сохраняет их в PNG без потери качества. Фоны копируются целиком.

## Структура

- `src/game/` — данные котов и улучшений, экономика и сохранение.
- `src/components/` — компоненты интерфейса.
- `public/assets/` — игровые изображения.
- `tools/` — утилита нарезки и её зависимости.
